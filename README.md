# Sauerbraten 64 bit Cheat

A game modification and reverse-engineering project for Sauerbraten 64 bit, developed for educational purposes and to explore game internals, memory structures, and debugging techniques.

## 🛠️ Tools Used

- **VSCode** — Code editing
- **IDA** — Reverse engineering
- **Cheat Engine** — Memory analysis
- **ReClass** — Memory structure analysis

## 🎯 Project Goals

- Explore the internal workings of Sauerbraten 64 bit.
- Learn reverse engineering and memory analysis.
- Investigate game data structures and memory layouts.
- Develop and test game modifications in a controlled environment.

## 🎮 Target

| Property | Details |
|---|---|
| Game | Sauerbraten |
| Version | 64 bit |
| Project Type | Game cheat / reverse engineering |
| Primary Focus | Memory analysis and game modification |


## ⚠️ Disclaimer

This project is intended for educational purposes and experimentation in controlled environments.

Use it responsibly and respect the game's terms of service, server rules, and other players. Do not use this project to disrupt multiplayer games or gain an unfair advantage over other players.
